# เก็บภาพหลักฐานของ waste-bank บน Cloudflare R2

## ต้องทำอะไร

1. สร้างบัญชี Cloudflare หรือใช้บัญชีของโรงเรียน แล้วเปิด **Storage & databases → R2 → Overview** และทำขั้นตอนเปิด R2 subscription ใน Dashboard แม้จะเริ่มจากโควตาฟรี ระบบอาจขอข้อมูลชำระเงิน และส่วนที่ใช้เกินฟรีอาจคิดเงิน
2. สร้าง bucket ชื่อ `waste-bank-evidence` แล้วเลือก **Standard storage** เพราะโควตาฟรี 10 GB-month ใช้กับ Standard เท่านั้น
3. ปล่อย bucket เป็น **private** ไม่เปิด Public Development URL (`r2.dev`) หรือ public custom domain เพราะภาพขยะอาจติดหน้าเด็ก บัตรนักเรียน หรือข้อมูลโรงเรียน
4. ส่งชื่อ bucket และ Cloudflare Account ID ให้ผู้พัฒนาได้ **ไม่ต้องส่ง API token, secret key หรือข้อมูลบัตร** ผู้พัฒนาจะเตรียม API ให้อัปโหลด/อ่านรูปผ่านการตรวจสิทธิ์เจ้าหน้าที่ แล้วให้เจ้าของบัญชีผูก R2 ผ่าน Dashboard/CLI
5. ก่อนเปิดใช้กับนักเรียนจริง ให้กำหนดว่าใครเห็นภาพได้ เก็บภาพที่อนุมัติกี่เดือน ตั้งการลบตามระยะเวลา และทดสอบสำรอง/กู้ข้อมูล

ระบบในเครื่องวันนี้ยังใช้ SQLite ยังไม่ได้เชื่อม R2 จึงควรเปิด bucket ก่อน แล้วค่อยย้ายการเก็บรูปขึ้น R2 และย้าย API/ฐานข้อมูลให้รองรับหลายเครื่องพร้อมกัน

## จำนวนรูปโดยประมาณ

R2 Standard ให้ฟรี **10 GB-month ต่อเดือน** คือพื้นที่เฉลี่ยที่เก็บ ไม่ใช่พื้นที่ใหม่อีก 10 GB ทุกเดือน สมมติเก็บรูปไว้ต่อเนื่องและคิด 10 GB ≈ 10,000,000,000 ไบต์

| ขนาดภาพหลังบีบอัด | เต็ม 10 GB ตามทฤษฎี | วางแผนใช้ 8 GB (เผื่อ 20%) |
| --- | ---: | ---: |
| 200 KiB | 48,828 รูป | 39,062 รูป |
| 300 KiB | 32,552 รูป | 26,041 รูป |
| **400 KiB** (ค่าที่ใช้ในเว็บ) | **24,414 รูป** | **19,531 รูป** |
| 500 KiB | 19,531 รูป | 15,625 รูป |
| 1 MiB | 9,536 รูป | 7,629 รูป |

สูตร: `จำนวนรูป = พื้นที่ไบต์ ÷ ขนาดรูปไบต์` ค่านี้สมมติว่าทุกรูปใหญ่ถึงเพดานจริง รูปเล็กกว่านั้นจะเก็บได้มากขึ้น

ตัวอย่าง: นักเรียน 500 คน ส่งคนละ 1 รูปต่อสัปดาห์ เป็นเวลา 40 สัปดาห์ = **20,000 รูป** หรือประมาณ **8.19 GB** ที่เพดาน 400 KiB หากส่ง 2 รูปต่อสัปดาห์จะเป็น 40,000 รูป หรือประมาณ 16.38 GB และเกินโควตาฟรี

เว็บย่อด้านยาวไม่เกิน 1280 พิกเซลก่อน และลดคุณภาพ/ความละเอียดตามลำดับจนเหลือไม่เกิน 400 KiB ถ้ายังใหญ่เกินจะขอให้ถ่ายใหม่ API ตรวจขนาดอีกครั้ง การบีบอัดอาจทำให้ข้อความเล็กบนภาพอ่านยาก ควรทดลองกับรูปขวด กระป๋อง และใบเสร็จที่โรงเรียนใช้จริงก่อนยืนยันเพดานนี้

รูปที่ถูกปฏิเสธตั้งค่าลบหลัง 30 วันในระบบทดลอง ส่วนรูปที่อนุมัติยังไม่ลบอัตโนมัติ ควรตกลงระยะเวลาเก็บรูปที่อนุมัติกับโรงเรียน และให้รายการ Coins/audit คงอยู่แม้ลบรูป
