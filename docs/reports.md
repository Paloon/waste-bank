# รายงานตามช่วงเวลา

เข้าเมนูเจ้าหน้าที่ → รายงานตามช่วงเวลา เลือกวันเริ่มและวันสิ้นสุด หรือใช้วันนี้ / 7 วันล่าสุด / เดือนนี้ แยกดูสรุป ขยะ Coins นักเรียน และรางวัล กดวันที่ในตารางรายวันเพื่อดูรายละเอียด และกดดูทั้งช่วงเพื่อยกเลิกตัวกรองรายวัน

## การนับ

- วันเริ่มและวันสิ้นสุดรวมทั้งวัน ใช้เขตเวลา Asia/Bangkok เลือกได้ไม่เกิน 366 วัน
- ขยะที่ส่งนับจำนวนรายการ ไม่ใช่จำนวนชิ้น วันส่งใช้ `at` ผลตรวจและน้ำหนักใช้ `reviewedAt` และการยกเลิกใช้ `cancelledAt` ไม่เดาวันอนุมัติจากวันส่ง
- สถานะของรายการส่งและรายการรอรับเป็นสถานะปัจจุบันของรายการที่สร้างในช่วงที่เลือก ไม่ใช่สถานะย้อนหลัง ณ วันสิ้นสุด
- Coins ใช้เวลาบันทึก ledger แยก recycle, adjustment เพิ่ม/ลด, redemption, refund และ opening ยอดใช้สุทธิอาจติดลบเมื่อคืน Coins จากรายการที่แลกก่อนช่วงรายงาน
- การรับรางวัลใช้ `completedAt` การยกเลิกใช้ `cancelledAt` หรือวันที่ refund ที่เชื่อมกับรายการเดิม รองรับประวัติที่ยกเลิกก่อนเพิ่มฟิลด์ cancelledAt
- จำนวนนักเรียนในแต่ละกิจกรรมนับ ID ไม่ซ้ำภายในช่วงนั้น ห้ามบวกจำนวนคนรายวันหรือข้ามกิจกรรมเพื่อสรุปคนทั้งช่วง นักเรียนที่ส่งหลายครั้งนับหนึ่งคนแต่จำนวนครั้งแสดงแยก
- การเข้าใช้มีเฉพาะ audit ของ login และสมัครสมาชิกนักเรียนที่ยังเก็บไว้ ไม่รวมการเข้าเว็บแบบไม่ระบุบัญชี ไม่รับรองประวัติย้อนหลังครบ และไม่สร้างยอดเข้าใช้สมมติจากการส่งขยะ
- ชั้นและห้องเป็นข้อมูลปัจจุบัน การลบข้อมูลนักเรียนและประวัติที่เกี่ยวข้องตามระบบเดิมทำให้ยอดรายงานย้อนหลังจากข้อมูลที่ยังเหลือเปลี่ยนได้

## ขอบเขตและการอ่านข้อมูล

API `/api/reports` ต้องมี session เจ้าหน้าที่ และตรวจช่วงวันที่ก่อนอ่านข้อมูล รายการรายละเอียดครั้งละ 50 แถว ยอดสรุปคำนวณก่อนแบ่งหน้า จึงไม่เปลี่ยนตามหน้าที่เปิด

Supabase ใช้ตาราง schema v2 เดิมผ่าน PostgREST ไม่ต้องรัน migration หรือเพิ่มสิทธิ์ ตารางรายงานดึงเฉพาะฟิลด์ที่ต้องใช้ ไม่ดึงรูป PIN หรือ tokens อ่านหลายหน้าจนหมดแม้ server จำกัดขนาดแต่ละหน้า และตรวจ version ก่อน/หลัง หากมีการเขียนพร้อมกันจะลองใหม่แทนการรวมข้อมูลคนละ snapshot

จำกัดชุดข้อมูลรายงานรวม 20,000 records รวมข้อมูลนักเรียน หากเกินจะให้เลือกช่วงสั้นลง ไม่แสดงยอดบางส่วนเป็นยอดทั้งหมด การเปิดรายงานอ่านข้อมูลเท่านั้น ไม่รัน maintenance หรือเปลี่ยน Coins/สต็อก

การทดสอบครอบคลุมขอบเขตวันตามเวลาไทย กิจกรรมคนละวัน จำนวนคนไม่ซ้ำ การคืนรายการเก่า การแบ่งหน้า ข้อมูลวันที่ไม่ครบ การเข้าถึงเฉพาะเจ้าหน้าที่ การอ่าน cloud ที่ถูกจำกัดขนาดหน้า และการเปลี่ยน version ระหว่างอ่าน Browser regression ตรวจแท็บ ตัวกรองรายวัน ช่วงว่าง รีเฟรช และการไม่ล้นจอมือถือ
