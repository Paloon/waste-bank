# Coins ตามจำนวน

อัตราปัจจุบันเป็นแต้มจูงใจให้แยกและทิ้งถูกที่ ไม่ใช่ราคารับซื้อขยะ: ขวดพลาสติก 5/ขวด, แก้วพลาสติก 2/ใบ, กระป๋องอะลูมิเนียม 5/กระป๋อง, กระดาษ 1/แผ่นเต็มประมาณ A4, แก้ว 3/ขวดหรือภาชนะสมบูรณ์, กล่องอาหารพลาสติกและกล่องเครื่องดื่ม 2/กล่อง, ซองขนมและถุงพลาสติก 1/ซองหรือถุง

ห้ามฉีกแบ่งหรือแยกอะไหล่เพิ่มจำนวน แต่ละครั้งส่งหนึ่งประเภท จำนวนเต็ม 1–1,000 หน่วย ประเภทที่ไม่มีในตัวเลือกหรือหลักฐานไม่ตรงกติกาให้ครูปฏิเสธ

รางวัลเดิม 80–300 Coins เทียบกับขวด 16–60 ขวด อัตรานี้ต้องประเมินจากงบรางวัลและการใช้งานจริง ไม่อ้างว่าสมดุลด้านต้นทุนแล้ว

นักเรียนเห็นยอดประมาณการก่อนส่ง ครูแก้ประเภท/จำนวนจากหลักฐาน ระบบคำนวณ Coins ทางเซิร์ฟเวอร์ ไม่รับยอด Coins จากไคลเอนต์ เก็บประเภทและจำนวนที่นักเรียนแจ้งเดิมพร้อมการแก้ของครู อนุมัติแล้วลงบัญชีครั้งเดียว

เก็บอัตรา ณ วันที่ส่ง สำหรับประเภทเดิม ถ้าครูเปลี่ยนประเภทใช้อัตราประเภทใหม่ปัจจุบัน รายการเก่าที่รอตรวจครูต้องกรอกจำนวนก่อนอนุมัติ รายการเก่าที่อนุมัติแล้วไม่เปลี่ยน Coins หรือน้ำหนัก ไม่แปลงน้ำหนักเป็นจำนวน

รายงานรวมจำนวนที่อนุมัติและแยกน้ำหนักรายการเก่า วันที่ส่งใช้ประเภท/จำนวนที่นักเรียนแจ้ง วันที่อนุมัติใช้ค่าที่ครูยืนยัน ข้อมูล JSON เดิมรองรับฟิลด์ใหม่โดยไม่แก้ schema

แก้อัตราเริ่มต้นและกติกานับใน shared/recycling.js แล้วเผยแพร่เวอร์ชันใหม่ ทั้งหน้าเว็บและเซิร์ฟเวอร์ใช้อัตราเดียวกัน


ซองขนมและถุงพลาสติกให้ 1 Coin ต่อซอง/ถุงเท่ากันทุกคน เพิ่มกล่องอาหารพลาสติกและกล่องนม/น้ำผลไม้ 2 Coins ต่อกล่อง โครงการให้แต้มจากหลักฐานการแยกและทิ้งถูกที่ ไม่ใช่การรับซื้อขยะ ไม่มีเงื่อนไขช่องทางขาย

แนบรูปขยะ 1 รูป และรูปถัง/จุดทิ้งอีก 1 รูปได้เมื่อภาพแรกเห็นไม่ครบ ครูดูได้ทั้งสองรูป รองรับการเก็บใน Drive การล้างตามอายุและการสำรอง/กู้คืนทั้งคู่ เมื่อส่งไม่สำเร็จข้อมูลอยู่ในหน้าปัจจุบัน กดส่งรายการเดิมด้วย key เดิมได้ ไม่บันทึกภาพค้างไว้หลังออกจากบัญชีหรือหมดเวลา

คู่มือหน้าแรกใช้ไอคอนแยกประเภท กดชื่อเพื่อดูตัวอย่าง วิธีนับ และคำแนะนำการทิ้งตามป้ายของโรงเรียน ไม่เดาสีถังหรือสถานที่จริง

ขยะอิเล็กทรอนิกส์และอื่น ๆ ไม่เปิดรับรายการใหม่จนกำหนดกติกา แต่เก็บรายการเก่าไว้

กระดาษลังไม่แสดงในตัวเลือกส่งใหม่และ API ไม่รับการส่งใหม่ ประวัติเก่าคงไว้ รายการเก่ารอตรวจสามารถตรวจให้เสร็จด้วยอัตราเดิม 3 Coins ต่อชิ้นได้
